# 네이버 신 증권 API 섀도 관찰 데이터 (한시적)

`run_naver_api_shadow.py` 가 매일 여기에만 씁니다. **실전 데이터가 아닙니다** —
화면·점수·스냅샷 어디에도 쓰이지 않습니다.

| 파일 | 내용 |
|---|---|
| `YYYY-MM-DD_shadow.json` | 그날 신 API 로 받은 것 (파싱본 + raw 표본 + 요청 로그) |
| `latest_compare.json` | 같은 날 실전 스냅샷과의 필드별 일치율 |

**왜 있나**: 네이버가 2026-09-10 구 증권 서비스 종료를 예고했고(#211), 대비로 파서를
만들어 뒀습니다(#212). 그 파서를 **전환 당일에 처음 돌려보는 것은 안전주의가 아니므로**,
구 출처가 살아 있는 동안 나란히 받아 매일 대조합니다(#213, 오너 지시).

**⏳ 이 폴더는 한시적입니다.** 이관이 끝나거나 관찰이 더 필요 없어지면
워크플로우(`.github/workflows/naver_api_shadow.yml`)와 함께 정리합니다 —
필요 없어진 주기 작업을 남겨두는 것도 상대 서버에 대한 낭비입니다(§0-3-2).
